## 一、核心理念

### 模式升级

```
手动模式 (1.x):  用户发现线索 → 用户逐只分析 → 用户判断决策
                         ↓
AI驱动模式 (2.0): AI主动扫描 → AI识别评分 → AI深度分析 → 用户确认决策
```

**目标：** 把用户从每天刷几百只股票的体力活中解放出来，AI完成90%的扫描和初筛工作，用户只需要做最终的确认决策。

### 3.3 评分模型

```
┌────────────────────────────────────────────────────────────┐
│                    评分器 (动态权重)                         │
│                                                             │
│  权重策略 (根据可用数据自动调整):                             │
│                                                             │
│  无基本面+无消息 → 技术60% + 风险40%                        │
│  无基本面       → 技术50% + 消息20% + 风险30%               │
│  无消息面       → 技术50% + 基本面30% + 风险20%             │
│  全就绪         → 技术40% + 基本面25% + 消息20% + 风险15%   │
│                                                             │
│  技术面得分计算:                                             │
│    基础分 20 + Σ(信号强度 × 0.25 × 衰减系数)               │
│    - 风险抵扣: MACD死叉-10.5, 放量下跌-6.5                 │
│    - 衰减系数: 第1个100%, 第2个80%, 第3个60%...            │
│                                                             │
│  等级划分:                                                  │
│    ≥82 强烈推荐 ← 值得重点关注                              │
│    ≥73 推荐关注 ← 信号明确                                  │
│    ≥62 建议观察 ← 需进一步确认                              │
│    ≥50 中性     ← 信号不明显                                │
│    <50 不推荐   ← 无有效信号                                │
└────────────────────────────────────────────────────────────┘
```

## 四、数据模型

### 4.1 ai_scan_records — 核心表

```sql
CREATE TABLE ai_scan_records (
    id                INTEGER PRIMARY KEY AUTOINCREMENT,
    scan_date         TEXT NOT NULL,         -- 扫描日期 YYYY-MM-DD
    scan_type         TEXT NOT NULL,         -- 'noon' / 'close'
    index_code        TEXT NOT NULL,         -- 'hs300' / 'csi500' / 'star50'
    index_name        TEXT NOT NULL,         -- '沪深300' / '中证500' / '科创50'
    code              TEXT NOT NULL,         -- 股票代码
    name              TEXT NOT NULL,         -- 股票名称
    score             REAL NOT NULL,         -- 综合评分 0~100
    change_pct        REAL,                  -- 当日涨跌幅
    price             REAL,                  -- 最新价
    confidence        TEXT,                  -- AI置信度标签
    summary           TEXT,                  -- 一句话摘要
    rationale         TEXT,                  -- AI多空逻辑文本
    technical_score   REAL,                  -- 技术面评分
    fundamental_score REAL,                  -- 基本面评分
    risk_score        REAL,                  -- 风控评分
    stop_loss         REAL,                  -- 止损价
    take_profit       REAL,                  -- 止盈价
    position          TEXT,                  -- 建议仓位 e.g. '10%'
    technical_signals TEXT,                  -- JSON 技术信号数组
    risk_factors      TEXT,                  -- JSON 风险因素数组
    market_summary    TEXT,                  -- 本次扫描市场摘要
    total_scanned     INTEGER,               -- 本次扫描总数
    signal_count      INTEGER,               -- 本次信号总数
    generated_at      TEXT,                  -- 生成时间
    created_at        TEXT DEFAULT (datetime('now','localtime')),
    UNIQUE(scan_date, scan_type, index_code, code)
);
```

**设计原则：** 每只信号股票一条记录，而不是全量JSON blob。好处：
- 可按分数/行业/信号类型 SQL 查询
- 支持聚合统计（平均分、分布等）
- 易于扩展字段

### 4.2 StockScore — 内存模型

```python
@dataclass

    market_cap: float              # 市值
    ai_summary: str                # AI摘要

    entry_price: float             # 建议入场价
    stop_loss: float               # 止损
    take_profit: float             # 止盈
    suggested_position: str        # 建议仓位
```

## 八、定时任务

### Cron任务 (crontab)

```bash
# 周一~周五 11:30 → 午盘扫描
30 11 * * 1-5 cd /Users/albertma/... && /opt/anaconda3/bin/python3 scripts/ai_scan_cron.py noon

# 周一~周五 16:00 → 收盘扫描
0 16 * * 1-5 cd /Users/albertma/... && /opt/anaconda3/bin/python3 scripts/ai_scan_cron.py close
```

### 自动处理

- 周末不运行cron
- 如果cron在非交易日运行 → `run_scan()` 自动回退到最近交易日
- 回退时 `scan_type` 自动切 `close`（历史数据只有收盘）
- 扫描结果自动持久化到 `ai_scan_records` 表

### 飞书推送

Cron执行完成后，结果摘要自动推送到飞书对话窗口。
