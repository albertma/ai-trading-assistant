## 一、项目概览

将传统**手动驱动**的投研分析（用户逐只翻看个股 → 判断信号 → 做笔记 → 决策）升级为**AI主动驱动**模式（AI自动扫描市场 → 识别机会 → 深度分析 → 生成报告 → 给出建议），用户只需做最终的确认决策。

### 核心理念

```
手动模式: 用户发现 → 用户分析 → 用户决策
                    ↓
AI驱动模式: AI发现+分析 → 用户确认决策
```

### 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Element Plus + ECharts + Vite |
| 后端 | Python 3.11 + FastAPI + Uvicorn |
| 数据 | SQLite（`~/Jarvis/ai_trading/stock_archive.db`） |
| AI模型 | DeepSeek V4（API Base: `https://api.deepseek.com/v1`） |
| 行情数据 | 本地CSV（`~/Jarvis/A股行情信息/`）+ akshare |
| 成分股 | CSV文件（HS300/中证500）+ DB查询（科创50） |
| 进程管理 | system后台运行 + cron定时任务 |

## 四、AI驱动层核心模块详解

### 4.1 信号检测器 (`signal_detector.py`)

**输入：** K线数据（`kline_daily`表）、基本面（`analysis_snapshots`表）
**输出：** TechnicalSignal[] + RiskFactor[]

#### 支持的技术信号

| 信号 | 条件 | 强度范围 |
|------|------|---------|
| 大阳线 | 实体 > 3% | 36~90 |
| 红三兵 | 连续3阳 | 70~85 |
| 锤子线 | 下影线 > 实体×2 | 75 |
| MACD金叉 | DIF上穿DEA | 80~90 |
| MA5/20金叉 | MA5上穿MA20 | 75 |
| 布林带突破 | 收盘突破上轨 | 65 |
| RSI超卖 | RSI < 30 | 60 |
| MA200上方 | 收盘 > MA200 | 50 |

#### 风险信号

| 风险 | 严重度 |
|------|--------|
| MACD死叉 | 70 |
| 放量下跌 | 65 |
| RSI超买 | 50 |

### 4.2 评分器 (`scorer.py`)

**动态权重策略：**

| 数据状态 | 权重 |
|---------|------|
| 无基本面+无消息面 | 技术60% + 风险40% |
| 无基本面 | 技术50% + 消息20% + 风险30% |
| 无消息面 | 技术50% + 基本面30% + 风险20% |
| 全部就绪 | 技术40% + 基本面25% + 消息20% + 风险15% |

**评分等级：**

| 分数 | 标签 | 建议 |
|------|------|------|
| ≥82 | 强烈推荐 ⭐⭐⭐⭐⭐ | 值得重点关注 |
| ≥73 | 推荐关注 ⭐⭐⭐⭐ | 信号明确 |
| ≥62 | 建议观察 ⭐⭐⭐ | 需进一步确认 |
| ≥50 | 中性 ⭐⭐ | 信号不明显 |
| <50 | 不推荐 ⭐ | 无有效信号 |

### 4.3 AI分析层 (`ai_analyzer.py`)

- 对Top信号调用DeepSeek V4生成深度解读
- 降级策略：API不可用时纯规则评分运行
- 增强：置信度调整（-10~+10）、交易建议

### 4.4 持久化 (`persistence.py`)

**表结构 `ai_scan_records`：**

```
id              INTEGER PRIMARY KEY
scan_date       TEXT NOT NULL       -- 扫描日期
scan_type       TEXT NOT NULL       -- 'noon'/'close'
index_code      TEXT NOT NULL       -- 'hs300'/'csi500'/'star50'
index_name      TEXT NOT NULL
code            TEXT NOT NULL       -- 股票代码
name            TEXT NOT NULL       -- 股票名称
score           REAL NOT NULL       -- 总分
change_pct      REAL               -- 涨幅
price           REAL               -- 当前价
confidence      TEXT               -- AI置信度
summary         TEXT               -- 一句话摘要
rationale       TEXT               -- 多空逻辑
technical_score REAL               -- 技术面评分
fundamental_score REAL             -- 基本面评分
risk_score      REAL               -- 风控分
stop_loss       REAL               -- 止损价
take_profit     REAL               -- 止盈价
position        TEXT               -- 建议仓位
technical_signals TEXT             -- JSON
risk_factors    TEXT               -- JSON
market_summary  TEXT               -- 批次摘要
total_scanned   INTEGER            -- 批次扫描总数
signal_count    INTEGER            -- 批次信号数
generated_at    TEXT               -- 生成时间
created_at      TEXT               -- 创建时间
```

UNIQUE约束: `(scan_date, scan_type, index_code, code)`

每只信号股票存为一条独立记录，支持 SQL 查询和聚合。

## 七、已知问题 & 待优化

### 技术债务

| 问题 | 描述 | 优先级 |
|------|------|--------|
| 🐌 扫描速度 | 500只股票K线逐个扫描，约30~90s | 中 |
| 🐌 OOM | 新机器内存不足16GB，build时偶发exit 137 | 中 |
| 📦 前端体积 | 单chunk > 2.7MB，未做code-split | 低 |
| 🧪 测试覆盖 | 无单元测试/集成测试 | 高 |

### 尚未实现（S3/S4规划）

- **S3 持仓监控**：将自选持仓股纳入每日AI分析
  - 持有股的异动检测
  - 持仓组合风险暴露
  - AI止损/止盈建议
- **S4 复盘优化**：基于历史扫描结果评估模型准确率
  - 预测vs实际的对照
  - 评分校准
  - AI模型微调

### 已知坑

| 坑 | 说明 |
|----|------|
| 周末回退+scan_type | 周末回退时必须自动切到close类型 |
| CSV编码 | A股CSV文件为UTF-16+Tab分隔 |
| macOS无timeout | cron脚本中不能用timeout命令 |
| 基本面数据 | 依赖analysis_snapshots表，需手动触发填充 |
| JSON序列化 | float('inf')不可JSON序列化 |
| 得分排序 | 同分股票需用涨幅或信号数量做二次排序 |
